# Paper Spotter

Grammarly-style review for PhD manuscripts. Upload a PDF, Word, or text chapter; flagged AI-sounding sentences, words, and paragraphs get replacements you can accept.

Local statistical detectors plus optional Grok 4.5 rewrites. Nothing is uploaded except optional Grok calls, the faculty verdict, and arXiv fetch.

## Review

Drop a paper or try a sample. The right pane shows AI / Mixed / Human mix, then **Sentences**, **Words**, and **Paragraphs** replacements.

## Stack

TanStack Start, Vite, Nitro (Vercel preset).
